# Rex mascot logo expressions

User direction: use the existing mascot as the logo, with different expressions. Exported directly from the current dashboard engine, not newly invented logos. All 16 expression configurations are included in individual red-and-white SVGs and expressions.png. Body is the same idle capsule sample at t=1; expressions change only the eyes and their projected gaze. No mouth or eyebrows.

Reproduce with `node design/logo/mascot-expressions-2026-11-08/export.mjs`. Export checks finite geometry, two eyes per frame and 16 distinct results. Uses the installed TypeScript compiler; no added dependency. Names are presentation labels, original IDs remain in filenames. Source animation engine attribution and MIT licence are retained in LICENSE.

These are expression studies using the established mascot. The neutral, curious, happy or proud poses are candidates for the primary logo; emotional variants can accompany status messages. No dashboard code or active application logo was changed. Trademark clearance not performed; this established character geometry derives from the existing Bloub-based mascot and is not asserted to be an exclusive new trademark.
