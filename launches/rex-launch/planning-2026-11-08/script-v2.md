# Rex — 56-second launch script / revision 2

Status: script and creative direction for review. No animation, installation, recording, paid voice generation or rendering authorized in this planning step.

Target: **56 seconds**, 19 beats, **115 spoken words** including user/Rex dialogue. At ~2.6 words/second this leaves roughly 11.8 seconds for UI reading, transitions and holds. These are editorial allocations, not measured voice timings. Retiming to the recorded voices must keep the final export between 50 and 60 seconds.

Format assumption: 16:9, 1920×1080, 30 fps, English subtitles. Main narration in warm Indian English; the user command demonstrates Hinglish. Record the Hinglish naturally; do not claim a specific number of supported languages or latency.

One story: ask for desk-lamp research → receive sources → save a shortlist → prepare a share message → review an approval. Memory and integrations are supporting beats. Confused is the primary brand expression; Excited is reserved for acknowledgement/completion. No mouth or eyebrows.

- Show real source results and real action states. Use a staged synthetic/test account and synthetic persona Arjun; capture no private inbox, calendar, contacts, tokens or third-party conversations. Existing seeded screenshots must be labelled illustrative if reused as demo output.

- Do not send external messages during production without the user authorizing the specific test recipient and message. The script works with the review/approval shown and no completed send. If a genuine test send is captured later, replace the review hold with its real confirmation without adding an unverified delivery claim.
