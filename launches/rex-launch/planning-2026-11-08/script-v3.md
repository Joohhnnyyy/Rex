# Rex — launch script / revision 3

**Target: 58 seconds · 16:9 · 20 beats · 105 spoken words.**

Rex is a personal voice sidekick: conversation connects to real work across web research, Mac apps and connected services; context survives calls; interests can feed background discoveries; routines make repeat work reusable. This script centres those capabilities instead of presenting Rex as a generic search-and-email dashboard.

English voice demo matches AgentConfig’s default. Hinglish is an optional alternate take only after multilingual mode is enabled and demonstrated. No fixed language count, speed guarantee, continuous screen watching, phone-call feature or always-on wake word is claimed.

## Production notes

- The main sequence is an edited demonstration of the existing share_research routine: research → write a message → open the named WhatsApp chat → send → verify the newest message matches. Do not imply that chat verification proves recipient delivery or that flight prices are booked/guaranteed.
- Source-grounded is not live-verified. Before production, capture a successful controlled run. If the workflow fails, revise the scene/claim; never fabricate the confirmation. Any accelerated sequence is labelled Edited for length. User authorization for the specific test recipient/message is required before any real outbound test.
- Use synthetic demo people/data. Use a controlled synthetic chat labelled Shanky; no real message is sent during this review production. Use genuine public source results without inventing prices or availability; keep private inbox/calendar content out of the capture.
- Memory is explicitly stored and loaded on later calls. Discover is scheduled research (default interval six hours, checked every 30 minutes) when Firecrawl, LLM, interests and background mode are configured. The Later insert is a separately captured result, not an immediate consequence of sending the message.
- The files follow-up is a separate request. The built-in share_research routine does not itself save a document; do not represent those links as saved until files.save_note or research_doc actually completes.
- Approval insert demonstrates gateway-gated actions such as Gmail send. It must not imply every desktop click or explicitly requested WhatsApp message triggers another approval. Meeting and coder specialists exist but their PR/meeting deliverables are not advertised in this cut without proof.
- Keep the supplied launch-video kinetic grammar: short spoken lines, one red keyword pill at most, voice-synced type, real UI, dark → light → dark. Openverse background photo at the opening; clean fields for product proof. Recorded real-SFX on actual events replaces the default synthesized effects; preserve narration/music stems.
- Confused remains the static brand logo; Excited is a momentary positive reaction. Art style remains unselected. No installs, animation or render was performed for this rewrite.

Pacing estimate: 105 words at 2.6 words/s ≈ 40.4s of speech, leaving ≈ 17.6s for UI reading and rests. Final duration must be measured after actual voice recordings; trim/retime within 50–60s. CTA URL and final voice source remain pending.
